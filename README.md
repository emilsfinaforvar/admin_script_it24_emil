# admin_script_it24_emil
Start with main.ps1 it will allow you to run all of the files in a much easier way. 
If you want to you can run them manually.
After each sucessful run it will create a log file and write to it with the results. Allowing you to copy the results into a new file.
After a logfile has been created it will write to it but will not be able to make another one.
Create-User.ps1
You can submit a name and a password and it will create a new user.
Install_software.ps1
It first asks if you want to get a selection of software or pick one yourself
If you pick 1 you will get to have a selection if you press 2 you will be able to pick one yourself.
Then it presents some alternatives like student teacher or administrator each with their own programs.
If you picked 4 it will give you some recommendations and then you can type a program to install.
Then it asks if you wanna uninstall or install 3 for install and 4 for uninstall
Then it should do the process and it's done
Log_base.ps1
Writes about current system stats like the current user what graphics card your using or the memory being used.
Then it logs it to the logfile like all other functions.
That is all, hope you enjoy using it as much as i did.
